What Irodori does

For toolchanger printers. It takes a colored model and picks 2–4 spools for it. Missing shades come from mixes: recipes in which consecutive layers print with different spools. The result is a 3MF project for Snapmaker Orca or ready G-code; the export profile is currently made for the Snapmaker U1. Everything is calculated on this computer: the server listens only on 127.0.0.1 and nothing goes to the internet.

Getting started

  1. Drop a model: GLB, OBJ (with .mtl files and textures), FBX (with textures) or a painted 3MF from Bambu/Orca/Prusa.
  2. Choose the number of toolheads and click Analyze.
  3. On the right, compare the results: spool colors, match with the model (%) and relative print time. The clicked result appears in the preview.
  4. Download the 3MF or click G-code to slice the project in Orca right away.

Preview

Print
the predicted look of the print (from card calibration, if you did one)
In slicer
exactly the colors Snapmaker Orca shows after opening the project. With one wall recipe they match "Print".
Model
the colors from the file, with brightness, saturation and rainbow if you turned them on
Priority brush
paint over an important part (face, logo) and recalculate: sets are chosen for that part, and the whole model is still exported
Base
15 patterns; a second click changes the size. It prints as a separate part of the same object.

Results

% match
100 − 2.5 × mean ΔE2000 error weighted by area. Use it to compare results of the same analysis.
time ≈1.3×
an estimate relative to the fastest result: surface area × number of spools in the recipe. G-code gives the exact time.
Accuracy
"Highest" searches sets across the whole library and picks mixes by how the eye sees color difference; analysis takes 2–4× longer. "Fast" skips that.
A / B / C
substitutes for the white or black spool in CMY sets
◎ and ↺
change a spool color to your own (the result is recalculated) and return to the suggested one
My colors
fill in by themselves from the spools in T1–T4 ("My filaments"); change any color and the result recalculates by itself

Settings

The dot next to a setting tells when it applies: a change requires recalculating, it applies to the next download.

Number of colors
"as many as needed" stops adding mixes when the next ones improve almost nothing; "spools only" does not mix
Two wall recipes
a separate pattern for the outer wall. Only uses pairs that Orca shows in the print color. Off by default: one recipe gives slicer = preview = print and is several times faster.
Color all the way in
color through the whole cross-section instead of only the wall band; usually fewer seams and a shorter print
Weave on flat tops
flat tops get a mix pattern instead of a single color
Merge specks
merges small color patches with their neighbors; fewer spool changes, less detail
Thick layers without mixing
the layer is thicker at heights where nothing is mixed
Thin layers under flat tops
flat tops with a real area get thinner layers
Sink into the bed
cuts that many millimeters off the bottom of the model
Blend overlays
semi-transparent decals and eyes in a GLB blend with the surface beneath
Rainbow
replaces the model colors with a rainbow spiral

Card calibration

Calibration → choose a set → download the 3MF card, print it, photograph it head-on in diffuse light, upload the photo and click the 4 corners. Print at the layer height you usually use. After recalculating, "Print" colors come from your photo instead of the mixing model.

The program reports the error on check tiles, which it left out of the fit, and compares it with the model alone. A calibration that improves nothing or has an error of ΔE 8 or more is not saved. Measurements belong to spools and their pairs, so another set of the same spools needs no new card.

Running on other systems

Windows
install Python 3.11+ from python.org, then double-click Irodori.bat
Linux
./run.sh

The first run creates a .venv folder and installs the dependencies. Snapmaker Orca (for G-code) and Blender (for FBX) are found automatically; set another path in IRODORI_ORCA and IRODORI_BLENDER.
